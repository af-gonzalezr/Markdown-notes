# MarkdownNotes

Un gestor de notas local creado con Spring Boot y Thymeleaf que permite escribir, guardar y visualizar archivos en formato Markdown.

## Tecnologias

* Java
* Spring Boot
* Thymeleaf

## Como ejecutar el proyecto

1. Clonar el repositorio:
```bash
git clone https://github.com/tu_usuario/MarkdownNotes.git
cd MarkdownNotes
```

2. Ejecutar la aplicacion:

   * En Linux / macOS:
```bash
./mvnw spring-boot:run
```

   * En Windows (CMD / PowerShell):
```cmd
mvnw.cmd spring-boot:run
```

3. Abrir en el navegador:
   Ingresar a `http://localhost:8080` para usar la aplicacion.
